# Systems Performance in Rust

Small, focused Rust programs that explore performance, memory behavior, and profiling. Each module targets a practical systems task with clear benchmarks and tradeoff notes.

## Focus Areas
- Streaming data pipelines and aggregation
- Cache structures and eviction strategies
- Parsing and serialization performance

## Planned Modules
- CSV/JSON aggregator with zero-copy parsing experiments
- Log processor with rolling stats and backpressure
- LRU cache with benchmark suite

## Benchmarks
- `criterion` suites for hot paths
- Profiling notes with flamegraphs and perf targets
